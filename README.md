# Monkey Leap

Browser endless-jumper game built with HTML, CSS, and JavaScript. Open `index.html` in Chrome (or any modern browser).

## Play

1. Open `index.html` in your browser
2. Space / click / tap to jump
3. Press R to restart

## Files

- `index.html` — page entry
- `style.css` — layout and visuals
- `game.js` — game logic
- `monkey-leap/` — unused Godot project (optional)

Controls: Space, Up arrow, click, or tap.
